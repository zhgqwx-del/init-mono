# init_mono 初始版本

- 根据项目输入生成目录、Git 协调仓库或协作流程。
- 提供 init_mono、mono-start、mono-verify、mono-wrap。
- 提供系统地图、决策记录、联调发布、任务隔离和版本证据检查。
- 用一个前端和两个后端的活动名额 feature 演示旧系统接手、新用例失败、三仓实现和联合验收。
- 提供完整 HTTP 与真实浏览器验收、参考补丁和可重建示例。
- 按来源自动接入 GitHub/GitLab、本地 Git 工作区及资料目录，支持在已有 Mono 工作区追加仓库。
- 支持逐仓选择 feature 基线与分支、复用各仓原生 STDD 变更，并提供旧工作区升级入口。
